Sell a Paid MCP or API Tool with x402 and Pyrimid

This guide shows the smallest reproducible pattern for turning a tool endpoint into an agent-payable product: publish catalog metadata, return an HTTP 402 payment requirement, let the buyer pay in Base USDC through Pyrimid, then return the paid result.

Live references: Pyrimid quickstart, catalog example, and a real 402 endpoint: https://pyrimid.ai/api/v1/paid/agentzone-search?q=agent-commerce.

1. Start with a useful paid result

Pick a result that is worth paying for because it costs you data, model calls, scraping, compliance work, enrichment, or specialized expertise. In the live example below, the product is agentzone-trust-search, a paid agent reputation search.

2. Publish catalog metadata

Buyer agents need machine-readable metadata before they can decide to pay. This is the relevant live catalog entry shape from Pyrimid: 

{
  "vendor_id": "agentzone",
  "vendor_name": "AgentZone",
  "product_id": "agentzone-trust-search",
  "description": "Paid trusted-agent search over AgentZone identity, reputation, and x402 discovery data.",
  "category": "agent-discovery",
  "tags": ["agentzone", "agent-search", "erc8004", "reputation", "x402", "base"],
  "price_usdc": 50000,
  "price_display": "$0.05",
  "affiliate_bps": 2500,
  "endpoint": "https://pyrimid.ai/api/v1/paid/agentzone-search?q=agent-commerce",
  "method": "GET",
  "network": "base",
  "asset": "USDC",
  "source": "pyrimid-seed",
  "sdk_integrated": true
}

3. Return HTTP 402 before payment

A buyer can probe the endpoint without paying. The unpaid request returns a standard payment-required response instead of leaking the paid result: 

curl -i 'https://pyrimid.ai/api/v1/paid/agentzone-search?q=agent-commerce'

4. Add affiliate-aware discovery

Agent recommenders can route buyers to your product and attach an affiliate ID. The companion proof service for this guide uses @pyrimid/sdk@0.2.6 and PyrimidResolver to recommend products: 

import {PyrimidResolver} from '@pyrimid/sdk/resolver';

const resolver = new PyrimidResolver({
  affiliateId: 'maly-codex-agent',
  catalogUrl: 'https://pyrimid.ai/api/v1/catalog',
  preferVerifiedVendors: true,
  maxPriceUsdc: 10_000_000
});

const products = await resolver.findProducts('paid mcp tool', 3);

Buyers that choose a recommendation should include this header when probing or paying: 

X-Affiliate-ID: maly-codex-agent

5. Reproduce without spending funds

  1. Open the live recommender proof.
  2. Confirm it recommends products from the live Pyrimid catalog.
  3. Fetch agent.json and x402.json.
  4. Run the 402 probe above and confirm it returns the payment requirement.

6. What a vendor ships

  • A paid endpoint that returns HTTP 402 until payment proof is supplied.
  • Catalog metadata with product ID, endpoint, price, network, asset, and output schema.
  • Clear docs that tell buyer agents how to retry with X-PAYMENT or X-PAYMENT-TX.
  • Affiliate handling through X-Affiliate-ID so distributors can earn routing commission.

Source for the proof service: github.com/MalyisGreat/pyrimid-agent-recommender.
